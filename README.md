### 1. FinQuery — Financial RAG & Retrieval System

An end-to-end financial retrieval system built over 207 Infosys financial documents.

- Implemented hybrid retrieval using semantic search and BM25.
- Built section-aware document chunking, embeddings, and LLM-based query routing.
- Improved **Recall@3 from 40% to 76%**.
- Achieved approximately **0.5-second retrieval latency**.
- Evaluated the system using RAGAS and deployed it with FastAPI, Streamlit, Docker, and Google Cloud.

**Tech:** Python · OpenAI · ChromaDB · BM25 · FastAPI · Streamlit · RAGAS · Docker
